
# Changelog

All notable changes to YT-DLP Helper are documented here.

## [Unreleased]

## [1.0.1] - Upcoming
### Added
- Remember the last selected download folder between application sessions.
- Automatically restore the saved folder on startup.
- Fall back to the default Downloads folder if the saved location no longer exists.

## [1.0.0] - 2026-10-08
### Added
- Windows graphical interface built with Tkinter.
- Video downloads with selectable resolution.
- MP3 audio downloads with quality options.
- Playlist downloading.
- Custom download destinations.
- Download progress indicator.
- Automatic filename formatting.
- Windows installer with bundled yt-dlp and FFmpeg.
